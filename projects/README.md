# projects

One folder per video you're working on — the workspace for an edit in progress.

Suggested layout for each project:

```
projects/2026-11-18_project-name/
├── brief.md        # goal, platform, length, audience, deadline
├── script.md       # script / talking points / transcript
├── notes.md        # edit decisions, feedback, revision history
└── working/        # intermediate renders, proxies, cut lists, subtitle files
```

Raw footage stays in `raw-videos/`; finished renders go to `exports/`.
