# raw-videos

Unedited source footage straight from the camera, phone, or screen recorder.

- Drop original files here untouched (MP4, MOV, MKV, etc.).
- Never edit or overwrite these — they are the master copies.
- Suggested naming: `YYYY-MM-DD_short-description.ext` (e.g. `2026-11-18_studio-interview.mp4`).
- Group a big shoot into a sub-folder if it helps (e.g. `raw-videos/2026-11-18_product-launch/`).
