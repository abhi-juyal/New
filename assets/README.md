# assets

Reusable building blocks for any edit.

| Folder    | What goes there                                        |
|-----------|--------------------------------------------------------|
| `music/`  | Background tracks and beds                             |
| `sfx/`    | Sound effects: whooshes, pops, risers, clicks          |
| `images/` | Stills, overlays, stickers, B-roll photos, textures    |
| `fonts/`  | Font files (TTF/OTF) used in titles and captions       |

Only add assets you have the rights to use. Note the license/source for each where possible.
