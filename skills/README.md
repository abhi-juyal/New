# skills

Reusable editing "recipes" and instructions for Claude.

Each file describes a repeatable workflow, for example:
- `captions.md` — how to generate and style captions
- `short-form-cut.md` — turning a long video into 9:16 shorts
- `silence-removal.md` — cutting dead air and filler words
- `color-grade.md` — the look to apply

Write them in plain language; Claude reads these before doing that kind of edit.
