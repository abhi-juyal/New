# brand-kit

Everything that makes a video look and sound like *your* brand.

- Logos (PNG with transparency + SVG if available)
- Color palette (hex codes in `colors.md`)
- Brand fonts (or put them in `assets/fonts/` and note which ones are "brand" here)
- Intro / outro bumpers, watermark, lower-third templates
- Tone of voice and caption style notes (`style-guide.md`)
