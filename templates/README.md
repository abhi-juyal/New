# templates

Starter projects for motion graphics. Copy one into `projects/<name>/` and edit it there.

- `remotion-starter/`: Remotion (React). A 1080x1920 title card. Render: `npx remotion render MyComp out.mp4`
- `hyperframes-starter/`: HyperFrames (HTML + GSAP). A 1080x1920 title. Render: `hyperframes render`
